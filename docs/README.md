## Principios fundamentales

1. **Explicar antes de evaluar:** definir conceptos, propósito, procedimiento y límites de lo que se observa.
2. **Distinguir hechos e hipótesis:** ningún registro aislado es necesariamente prueba de compromiso.
3. **Ejercicios seguros:** los registros y artefactos de entrenamiento son sintéticos, salvo que se etiqueten expresamente con fuente y procedencia.
4. **Fuentes verificables:** enlazar a documentación oficial y marcar las interpretaciones propias.
5. **Accesibilidad:** instrucciones comprensibles en español; indicar si alguna sección aún no está traducida.
6. **Progreso gradual:** rutas guiadas, ejercicios con pistas y modo experto.

## Nota sobre versiones

El repositorio ha crecido mediante entregas incrementales. El README principal conserva notas históricas de varias versiones; no debe entenderse como un inventario actualizado de funciones o una garantía de que todas estén verificadas visualmente. Estas guías describen la estructura consultada en el repositorio y deben actualizarse junto con el código.

## Publicación

El punto de entrada de la web es `index.html`, en la raíz. Antes de mover archivos JS, CSS o recursos hay que actualizar referencias y verificar GitHub Pages. Este primer trabajo documental **no mueve código**.
